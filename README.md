# dataset_cooperative_backend

Basic Python Flask web application boilerplate for future image upload and analysis workflows.

## Quick start

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:5000

## Run tests

```bash
python -m unittest discover -s tests -p 'test_*.py'
```
